## Keep unchanged (proven in 006)
Rules in context (start, compaction, artist message, every N calls); no build tools for the main chat; referee after every builder run; QC + engineer at unit end; one builder per unit, `MAX_BUILDERS`; `SHARED:` holds; publish-only review scene; report ownership; ABORTED reports; PAUSE; STOP_AT; logs. In 006 they held across one compaction.

## Invariants (Harbour test, 2026-11-13) – every hook change keeps them, each has a test
- **Parallel-safe:** starts in one message pass the gate one at a time (`review/gate/start.lock`), so each run gets its own number.
- **Write-once:** a report in `review/iter/` belongs to the agent that wrote it; no other agent overwrites it (`report_authors.tsv`).
- **No dead ends:** every duty the gate names can be started exactly as named. Packages (`<unit>-<package>`) count as part of their unit wherever the unit is checked: QC, visibility map, integrate.
- **A way out:** a wrong refusal goes to the artist or the hook session (`SendMessage` to `local_…`), never around the gate.
